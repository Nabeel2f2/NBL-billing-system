🚀 Project Showcase: POS & Sales Management System

I'm excited to share a project I've been working on — a Point of Sale (POS) & Sales Management System developed using C# and .NET Windows Forms. Selecting a POS system as my project work is a great choice taken within this project as it gave me a profound confidence to handle with practical systems.

This project was built to provide a practical solution for managing day-to-day operations of a retail/food business, including:

🔹 Product management

🔹 Employee management

🔹 POS billing & invoice generation

🔹 Product search and selection

🔹 Shopping cart / billing interface

🔹 Sales records and transaction management

🔹 Discount and total calculations

🔹 SQLite database integration

🔹 DataGridView-based data management

🔹 Modern and responsive UI using Guna UI

🔹 Local database storage without requiring SQL Server

One of the biggest parts of this project was moving from SQL Server to SQLite, allowing the application and database to be deployed together without requiring a separate database server.

Through this project, I gained practical experience with:

💻 C# & .NET

🗄️ SQL & SQLite

🎨 Windows Forms UI development

🔄 CRUD operations

📊 Database integration

🐛 Debugging and problem solving

📦 Application deployment

This project has been a great learning experience and helped me understand how different parts of a software application — UI, business logic, database, and deployment — work together.

I'm continuing to improve the system and add new features as I learn more.
